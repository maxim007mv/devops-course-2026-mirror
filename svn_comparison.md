# Git vs SVN

1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — указатель на коммит, создаётся мгновенно. В SVN ветка — копия директорий на сервере, это медленно.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN централизованный: коммит сразу на сервер. Без сети коммит невозможен.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
В legacy-проектах (госсектор, банки) и когда нужна жёсткая централизация на одном сервере.
