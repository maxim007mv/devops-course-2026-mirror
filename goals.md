# Цели на семестр

1. Освоить Docker: уметь писать Dockerfile, собирать образы и запускать контейнеры для учебных проектов.
2. Настроить CI/CD на GitHub Actions: автоматическая проверка и деплой после каждого push.
3. Уверенно работать в Linux (Bash): скрипты автоматизации, systemd, основы сетей для DevOps-задач.
